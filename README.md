How to play:


WASD/Arrow Keys to move


E to interact/pick up items


Left mouse button to select items/hold out items from the inventory


There are 8 different cats and each cat has a specific item that they want. When you find that specific item, select it from the inventory to "hold it out" and the cat will follow you. Lead all 8 cats back home and you win the game! (See itch.io page for more detailed instructions and an example walkthrough video).


I made this game for Girls Got Game Jam where the theme was "attract". I wanted to make a cozy game with cats, something that I haven't done before!


This project was made with Unity for the code and Aseprite for the art! The BGM is a free asset found online.


I mostly struggled with using Unity since it was a new software for me, and especially about how the physics works with the colliders. I was able to leearn more about Unity and get used to how it works which will be helpful for future projects!
